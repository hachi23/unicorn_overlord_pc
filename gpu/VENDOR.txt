Until the native renderer replaced it (branch claude/native-renderer, 2026-11), gpu/ vendored
shadPS4's video core, shader recompiler and Gnm/VideoOut libraries
(https://github.com/shadps4-emu/shadPS4, commit b4e7ae776071ceb1dd35004577a8719481e1d258,
GPL-2.0-or-later). None of that code is built any more; it was deleted.

What still follows shadPS4 (GPL-2.0-or-later, the license of this project too):
  platform/equeue.cpp                          the VideoOut event data packing
  platform/video_out.cpp, platform/gnm.cpp     error codes and the values of calls retail
                                               firmware does not have
  src/runtime_videodec.c, src/runtime_mp3.c    structure layouts (marked in the files)

Other vendored code under gpu/third_party: imgui (MIT, submodule), fonts (DejaVu), anime4k
(MIT, generated into platform/shaders/anime4k by tools/anime4k.py). The FSR shader headers in
platform/shaders (ffx_a.h, ffx_fsr1.h) are AMD's (MIT).
